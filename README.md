# .github

This repository holds **organization-wide default files** for [claudeusers](https://github.com/claudeusers).

It's not a project itself — it's configuration. Files here (Code of Conduct, Contributing guide, issue templates, etc.) automatically apply to every public repo in the organization that doesn't define its own version.

> ⚠️ **claudeusers is an unofficial, community-run organization for people who use [Claude](https://claude.ai) by Anthropic.** It is not affiliated with, endorsed by, or sponsored by Anthropic, PBC. "Claude" is a trademark of Anthropic, PBC, used here descriptively.

## What's in here

| File | Purpose |
|---|---|
| `CODE_OF_CONDUCT.md` | Behavior standards for everyone participating across our repos |
| `CONTRIBUTING.md` | How to contribute to any claudeusers repo |
| `SUPPORT.md` | Where to get help vs. where to file a bug |
| `SECURITY.md` | How to responsibly report a security issue |
| `.github/ISSUE_TEMPLATE/` | Default issue forms |
| `PULL_REQUEST_TEMPLATE.md` | Default PR checklist |

Learn more about how GitHub uses this repo: [Creating a default community health file](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
